# Realistic qualification frozen baseline

`validation_checksums.sha256` is the maintainer-frozen realistic qualification baseline.

It was frozen only after the exact ENA FASTQs, the qualified GDC installation,
and one production-style execution profile completed **two clean realistic runs** whose
generated `results/run/validation_checksums.sha256` files were byte-for-byte identical.

The frozen subset is generated by the normal pipeline and deliberately excludes BAMs,
MultiQC HTML, timestamped provenance, and environment-dependent metadata.

Partners do not regenerate this baseline. Their realistic qualification run is compared against
the maintained file by `validate_results.py`. One ordinary partner run is sufficient when it
reproduces this authoritative baseline unchanged.

Consortium sites follow `docs/users/consortium/SOPs/SOP-02-site-qualification.md`.
`tests/real/README.md` provides technical fixture/validator detail, and
`docs/maintainers/qualification-baselines.md` defines maintainer baseline-change procedure.
